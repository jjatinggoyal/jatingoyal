# Welcome to My Blog!

This is an example blog post written in MDX. MDX allows you to use React components right inside your markdown!

  This is a default info alert. It's perfect for general information and tips.

## Features

- **Markdown Support**: Write content in markdown format
- **React Components**: Use React components in your markdown
- **Syntax Highlighting**: Code blocks are automatically highlighted
- **Frontmatter**: Add metadata to your posts
- **Image Optimization**: Images are optimized using Next.js Image component

```typescript
interface BlogPost {

function formatDate(date: string): string {
  return new Date(date).toLocaleDateString('en-US', {
    year: 'numeric',
    month: 'long',
    day: 'numeric'
  });
}
```
